# Artwork provenance

The two engineering-art WebP sources were generated with the built-in image generation tool. Prompt direction: text-free cinematic engineering landscapes; translucent server monoliths on the right, quiet negative space on the left; restrained cyan/violet illumination; midnight and pearlescent daylight variants; no people, logos, or application UI.

cinematic-hero PNGs composite these backgrounds with exact typography from hero-type SVG sources. Hero-motion SVGs are original vector animation. Project cards, toolkit and footer are original programmatic vector art, enriched from the previous committed versions. All project illustrations are conceptual, not screenshots.

Motion uses self-contained SVG CSS, without scripts or external fonts. Custom SVGs honor prefers-reduced-motion; GitHub contribution snake is generated by the existing workflow. Browser support for motion preferences inside embedded images varies.

Original vector hero assets are retained. No application or deployment was modified.

Cinematic hero WebPs add a 32-frame, eight-second loop with vector-generated ambient glow, drifting particles and an orbital point. Exact SVG typography was composited before encoding. Static PNGs are selected by the README picture element for reduced motion. Full subtitle cycling stays in lightweight vector banners.
